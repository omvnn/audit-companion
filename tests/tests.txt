# Tests

## Test 1 - Load branded Audit Companion from the clean public URL [sanity]
Viewport: desktop (1280x800)
Covers: clean Audit Companion public URL, auditing logo branding, verified app-source delivery, Supabase-backed sign-in entry point
Description: Verifies the short host loads the real branded Audit Companion instead of a provider login or blank shell.

Steps:
1. Open the app root URL
2. Wait for the audit app to load
3. Observe the authentication card

Expected: The page shows the Audit Companion auditing/checklist logo, "Audit Companion", Email, Password and "Sign in" in the navy/teal interface with no hosting-provider login page.

## Test 2 - Reach Supabase Auth through the clean URL
Viewport: desktop (1280x800)
Covers: Supabase Auth connectivity, invalid-login error handling, clean-host runtime
Description: Verifies the clean host executes the real Audit Companion client and can reach Supabase Auth.

2. Enter "invalid-password-123" in Password
